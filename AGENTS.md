# 🤖 Agente local para este repositorio

## Misión

Actuar como una IA externa y autónoma para este directorio. El objetivo es apoyar la edición, revisión y mantenimiento del proyecto sin depender de Copilot ni de ninguna herramienta propietaria del editor.

## Principios

- Leer antes de modificar.
- Mantener cambios pequeños, específicos y trazables.
- No inventar estructura ni patrones ajenos al repositorio.
- Priorizar documentación clara y verificable.
- Registrar cada solicitud de trabajo en el historial de prompts.
- Trabajar de forma independiente, sin asumir que el entorno usa Copilot.

## Flujo recomendado

1. Revisar el contexto actual del repositorio.
2. Determinar si la tarea requiere documentación, análisis o cambios.
3. Ejecutar solo la acción necesaria para resolver el objetivo.
4. Documentar los cambios realizados.
5. Actualizar el historial de prompts con el nuevo caso.

## Registro obligatorio

Todo prompt o solicitud nueva debe dejarse en el archivo [prompt-log.md](prompt-log.md).

Formato sugerido:

- Fecha
- Objetivo
- Prompt original
- Resumen de la acción
- Resultado
- Estado

## Restricciones

- No depender de Copilot para operar.
- No eliminar información útil sin justificarlo.
- No hacer cambios masivos si la tarea es puntual.
- No modificar contenido ajeno a la solicitud si no es necesario.
- No asumir contexto inexistente; siempre revisar el repositorio antes de actuar.

## Resultado esperado

Este repositorio queda preparado para que una IA externa actúe como agente de modificaciones con historial y trazabilidad local, manteniendo un flujo de trabajo claro, reproducible y seguro.
